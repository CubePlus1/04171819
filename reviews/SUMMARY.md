## §1 · 结论先行

**10 份原型，0 份直接可用，但问题高度一致。**
不是风格做得烂，是 Gemini 在生成时**系统性误解了产品定义**——把"履约型内容"做成了"AI 购物助手/监控/比价"。这意味着修复路径非常明确：**先把语义拉回"蹲到了"原则，再谈视觉打磨**。

**一句话判断**：这不是要重做 10 次，是要**选 1–2 套视觉壳 + 统一修语义**。

## §3 · 10 份全中的 8 条共性硬伤

无论风格如何，下面这些毛病几乎每一份都有，**vibe coding 修复时要把这 8 条做成统一校验清单**：

1. **产品语义漂移** → 从"履约型内容"滑成"购物助手/监控工具/促销卡"
2. **P1 不成立** → 首屏没有"你 X 周前在 XX 蹲过 YY"情景还原行，或藏到了 P2
3. **P1/P2/P3 职责错位** → 大量把 P3 做成"购买 CTA"而非"行为足迹"
4. **禁用词遍地** → "监控 / 精准 / 科技前沿 / LLM / 置信度 98% / Context Aware / 立即购买 / 全网扫描 / CYBER_HUNTER"
5. **输入框是摆设** → 评委手打无法驱动不同结果，只有预设能触发
6. **swipe 未兑现** → 全部都是点 dot / 点按钮 / 自动轮播（违反手动横滑原则）
7. **演示状态不重置** → 重复演示时 P2/P3 残留，第一秒成立崩
8. **CTA / 翻页事件冲突** → 整卡点击翻页把 CTA 吃掉，或 CTA 冒泡又翻到 P2

## §4 · Top-3 候选深度对比

### S2 · 小红书软萌（综合 6.2 · 最推荐）
- ✅ **情景还原行做对了**——第一行"你 3 周前在...蹲过..."基本命中
- ✅ 视觉系统完整，温暖治愈基调贴合
- ✅ wow moment 成立：预设 → 工作流 → 卡片滚到视口中央
- ❌ 大量"全网最低价/建议直接冲/智能买手"——A 剧本带货味严重，需删
- ❌ 只有一张固定卫衣卡，没做 A/B/C 剧本分化
- **修复成本**：中（语义改造 + 剧本分化，不碰视觉骨架）

### S1 · 抖音原生（综合 6.1）
- ✅ 赛道三天然契合，抖音 feed 骨架最强
- ✅ Agent → feed 的演示链路清晰
- ❌ "System Operational / Match Accuracy 98.7%" 赛博终端感抢戏
- ❌ 所有预设都触发同一张卡，没剧本分化
- ❌ 卡片预埋在第二屏用 opacity 控制，不是真"浮出"
- **修复成本**：中（改语气 + 真动态注入 feed）

### S7 · Bento Grid（综合 5.4，但架构最好）
- ✅ `scripts[]` 配置化做得最干净，后续扩剧本成本低
- ✅ 白底多彩块符合 2024-2025 视觉趋势
- ❌ P1 重置 bug：第二次演示可能直接从 P2/P3 开始
- ❌ 整卡 click 吞 CTA；"置信度 98% / 预售" 冷数字
- **修复成本**：中偏低（架构底子好，文案改一轮）

## §5 · Vibe Coding 建议路径

### 推荐路径 A（稳）
**选 S2 小红书软萌主稿** + **抄 S7 的 `scripts[]` 架构** → vibe coding 修 8 条共性硬伤。
- 优势：情感基调最贴合，架构底子最稳
- 风险：小红书风格和"抖音原生"有微妙冲突，但用户在 principle.md 里已允许"温暖治愈 + 抖音原生"并列

### 推荐路径 B（冲）
**选 S1 抖音原生主稿** + **抄 S7 的 `scripts[]` 架构** → vibe coding 修 8 条共性硬伤。
- 优势：赛道契合最强，评委 3 秒内"哦这是抖音"
- 风险：要把现在的赛博终端感彻底去掉，回到温暖语气

### 不推荐重跑 10 次
- 10 份同一个根错（语义漂移）再做一轮还会再错。
- **根本修复点在 prompt**：下次给 LLM 生成时，要用 A/B/C 剧本的完整情景文案直接嵌入 prompt，让模型没机会发明"智能买手"。

## §6 · 硬伤修复清单（可直接塞进 vibe coding prompt）

这段话可直接 copy 丢给下次生成的 AI：

```text
硬约束（违反即重写）：
1. P1 第一行必须是模板："你 {3周/一个月/2周} 前在「{博主/视频}」里 {蹲/按了稍后再看/评论了} {主题}"
2. P1 必须单独成立（不翻页也能让人说出"啊，这是我之前蹲过的"）
3. P2 = AI 用自然语言解释"我为什么给你这个"（禁止冷数字/置信度/LLM/Context Aware）
4. P3 = 行为足迹"你这段时间蹲过 N 次同类"（禁止购买 CTA）
5. 禁用词：监控 / 精准 / 全网扫描 / 立即购买 / 算法匹配度 / LLM / Context Aware / CYBER_HUNTER / LOOT
6. 允许词：被记得 / 念念不忘 / 蹲 / +1 / 姐妹们 / 催更 / 接回来 / 回响
7. 预设评论必须驱动不同剧本（A 蹲链接 / B 稍后再看 / C 蹲后续），不是都指向同一张卡
8. 输入框必须真可输入（不能 readonly），自由输入要进 workflow
9. 每次触发必须重置到 P1（防重复演示残留）
10. 翻页用手动横滑或左右箭头，禁止自动轮播
11. CTA 必须 stopPropagation 防冒泡到父级翻页
12. A 剧本禁止"立即购买 / 限时优惠"，用"你当时蹲的终于放出来了"
```
