# 02 · 主 demo 详细分析

> `dundao-demo` / `feat/dundao-demo` · 加权总分 **7.95**

## 形态速览

双面板 TikTok 信息流 demo：
- **左面板**：抖音信息流模拟 · 履约卡片自动浮入下一条位置
- **右面板**：AgentMind（5 相位可视化）+ 5 步折叠细节 + TriggerPicker（展台控制）
- 自动节奏：9 秒一次 ambient tick · 也可手动点 A/B/C 剧本触发器
- 12 套可切换视觉主题（暖色治愈 / 赛博霓虹 / 极简杂志 / ...）

技术栈：
```
后端：Express + better-sqlite3 + ws
前端：React 18 + Vite + Tailwind + Framer Motion + Zustand
契约：shared/contracts.js（WS_EVENTS / REASON_CODES / MIND_PHASES）
测试：smoke + cardBuilder.test + 10 轮 codex review
```

## 最强点

### ★ 左面板字面就是"信息流的下一条"

赛道三原题：
> "我们希望创造一种新的信息流内容单元 · 像信息流中的'下一条内容'一样成立"

主 demo 的左面板**物理成立**这件事：
- 是真实 TikTok 风格信息流（竖屏卡片、可滑动）
- 履约卡片**插入在信息流里的下一条位置**
- 没有弹窗、没有跳转、没有新页面
- 卡片上自带 P1 情景锚点 · 用户一眼认出

**这不是靠 pitch 说服评委相信的** · 是他们看到左面板那一秒的直接认知。

### ★ 爷爷剧本情感高峰

3 剧本中，剧本 C（蹲后续爷爷真帅）是评委体验的情感炸点：
- P1 情景句："你 2 周前在爷爷档案下评论过蹲后续爷爷真帅"
- 答案：后续视频 + 10 秒前情提要
- 收束："你当时惦记的那句后续 · 我替你等到了"
- 情感锚点是**被记得**，不是带货

展台上这个剧本演完，评委的第一反应是"这一条我想收下来"—— 产品目标达成。

### ★ MindCanvas 把 AI 前台化

赛道三的 AI 能力评审不是"用了 LLM 多厉害" · 是"AI 是否支撑体验本身"。
MindCanvas 把 AI 的 5 个决策相位（扫描 → 挑中 → 配对 → 原子声明 → 浮出）全部可视化：
- 评委看见节点呼吸、focus 放大、连线点亮、金印落下、卡片飞出
- AI 不是黑盒算法，决策可审计
- 这本身是产品主张 · 不是技术展示

### ★ 12 套主题切换 · 展台视觉冲击力

这是展台观众停留 3 秒的钩子：
- 暖色治愈（默认）· 赛博霓虹 · 极简杂志 · 软糖粘土 · 迷雾玻璃
- 新野兽派 · 像素千禧 · 手记纸本 · 森林自然 · 霓虹港风 · 水墨禅意 · 剪贴簿
- 按 `[` `]` 键快速切 · 路人想不停都难

### ★ 技术层面稳定

10 轮 codex review 覆盖过 concurrency / shutdown / CORS / rate limit / a11y / performance / maintainability / testing / integration / copy。
smoke + unit + integration 测试全绿。
展台插公网 WiFi 也不担心出事。

## 最致命的问题

### 双面板 = 不是真实产品形态

评委看到屏幕**第一个疑问**：
> "这右边是干嘛的？真实产品里存在吗？"

**如实情况**：
- 真实产品 UI 只有左面板（信息流 + 履约卡片）
- 右面板是**展台 demo-only**，给评委看 AI 在想什么
- 它的存在价值是"透明化 AI 决策"，不是真实功能

这意味着评委看到的 50% 屏幕面积是**展台视图而非产品**。
这是一个**结构性质疑**，不是 bug。

### 为什么这个弱点可翻盘

Pitch 里要**主动地**说清这件事：

> "您看到的是一个 pitch 视图 · 不是最终产品 UI。
> 右边是 AI 决策透明化视图，给您审查 AI 做了什么。
> 真实产品用户只看左面板信息流 + 卡片。"

**这一句话**能把质疑翻成加分：
- 展示了你对真实产品形态的清晰思考
- 把 "AI 透明化" 这个价值前置
- 比被动等评委提问更主动

如果怕没说服评委，展台上加一个单面板 URL（`?panel=product-only`）能当场演示纯产品形态。10 分钟工程成本。

## 次要弱点

### 右面板文案有 demo 术语

像 "触发一次信号" 这类词是 demo-only 语言，暴露了展台身份。
醒来后的优化点之一：砍掉这些词，改成更产品化的文案。

### 部分主题对比度弱

12 套主题里几个偏极端的（新野兽派大黄色、霓虹港风纯黑）在展台投影仪上可能读性差。
fallback：展台默认锁定"暖色治愈"主题，展示过程中不切换。

### 主题切换本身分散注意力

评委可能因为 12 主题 cool 而专注切主题 · 忘了看核心 demo。
fallback：展台默认关主题切换入口 · 需要时自己切。

## 为什么符合赛道三

用赛道三评审锚点的 5 个问题逐个检查：

1. **刷到即懂**：是 · P1 情景锚点 1 秒读出是谁的事
2. **不需要跳转**：是 · 卡片就在信息流里，不弹出、不跳转
3. **不需要学习成本**：是 · 卡片自带答案，没有"点 X 看 Y"的操作
4. **极短时间获得满足**：是 · 整个 tick 2 秒 + 评委看卡片 5 秒 = 7 秒闭环
5. **自然产生一次互动/使用**：是 · 可选手指左右滑看 P1/P2/P3 多页

**5 条全中**。这是主 demo 最有底气的地方。

## 对比：不符合赛道三的假设形态（反面验证）

如果主 demo 改成这样，就会符合不了：

- ❌ 卡片出现时弹窗 + 进入详情页 · 需要跳转
- ❌ 卡片需要用户点"查看" · 需要互动才能看到内容
- ❌ 卡片里只有"这是你蹲过的" · 没有答案 · 需要用户再点进去
- ❌ 卡片内容需要用户学习一套符号/规则 · 有学习成本

主 demo 规避了全部这些陷阱。

## 展台演示路径（推荐）

**推荐顺序** · 覆盖 3 剧本但不过长：

```
1. 评委站定 · 解释一句 "这是履约型内容"         (10s)
2. AI 自动节奏 · 卡片 A 浮入 (剧本 A · 蹲链接)   (10s)
3. 手动触发剧本 C · 深演 (爷爷剧本)              (30s)
4. 指 MindCanvas 讲 5 相位                       (20s)
5. 收尾 · 过去 × 此刻 · 一人一张                 (10s)
──────────────────────────
总计                                            ~80s
```

90 秒内完成。如评委给更多时间，加剧本 B 快闪（~15s）。
