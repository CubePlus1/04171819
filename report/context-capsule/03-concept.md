# 03 · 核心概念 + 重新定义"懂你"

## 核心概念：情境预言胶囊（Context Capsule）

一种新的信息流数据单元 —— 既不是卡、不是视频、不是对话。

它是一个**情境对象**（situation object），具备 **7 个底层属性**：

| 属性 | 含义 | 体现层 |
|---|---|---|
| 1. 可执行 | 决策层直接出成果（不是"建议"，是"行动"） | Layer ④ |
| 2. 可变形 | 同胶囊换参数重渲染，不换身份 | Layer ⑤ |
| 3. 可反馈 | 用户反馈直接回写 `situation_vec` | Layer ⑥ |
| 4. 可审计 | Agent trace 让每条 evidence 可追源 | Layer ⑦ |
| 5. 带时间预言 | 双时间：`now`（识别时刻）+ `predicted_moment`（预言目标） | Layer ① |
| 6. 多轨模态 | 视觉 + 听觉 + 结构化 + 证据，同步编排 | Layer ②③ |
| 7. 情境原生 | 不是面向"用户"生成，是面向"情境"生成 | Layer ① |

详细 Schema 见 [`04-schema.md`](04-schema.md)。

---

## 为什么叫"新数据形式"

"新"不是宣传词，是有对比依据的。

| 维度 | 传统 feed 卡 | 传统 LLM 回答 | **情境预言胶囊** |
|---|---|---|---|
| **时间** | 单点（发布时间） | 单点（响应时间） | **双时间**：`now` + `predicted_moment` |
| **情境** | 无 | 对话上下文 | **情境向量**（可被机器对齐、可漂移） |
| **模态** | 单一（视频 / 图文） | 文本 | **多轨**：视觉 + 听觉 + 结构化 + 证据 |
| **决策** | 点赞 / 评论 | 无 | **成果 action**（直接执行） |
| **变形** | 不变形 | 重新生成（丢失上下文） | **参数化变形**（同胶囊换参数重渲染） |
| **反馈** | 黑箱推荐 | session 级 | **向量锚点**（可解释回写） |
| **可审计** | 无 | 黑盒 | **Agent trace 层可追溯** |

每一行都是一个**结构性区别**，不是程度不同。
比如"双时间"——传统卡 **没有** `predicted_moment` 这个字段，不是"预言能力弱"，是**字段不存在**。
这种"字段维度的不同"定义了一种新数据类型，就像 JSON 和 XML 的差异不是"更好用"，是**结构模型不同**。

## 重新定义"懂你"

本方案最关键的哲学转移。

### 传统定义

> **"懂你" = 系统预测个体用户的偏好并精准投喂。**

这个定义在游园会展台**结构性地失效**（详见 [`02-pain-points.md`](02-pain-points.md) 痛点 4）：
观众不是被懂的主体（不是 TA 自己的数据），因此所有"精准个性化"的 wow 在展台上都立不起来。

### 本方案的重定义

> **"懂你" 不是懂你是谁，是懂你此刻所处的情境。**

观众和路过的人**共享同一个"此刻"** ——
- 4 月 17 日的春末
- 距五一假期 14 天
- 下午 3 点的微雨
- 大学生群体正在讨论出游

当系统识别"此刻"并为"此刻"生成胶囊，**每一个身处"此刻"的人都被懂了**。

这不是"假装懂你"，是把"懂"的颗粒度**从个体换成了情境**。

### 三个层次的"懂"

| 层次 | 定义 | 示例 | 展台可感知 |
|---|---|---|---|
| L1 个体懂 | 懂你这一个人 | "Hi 张三，你爱吃辣" | ❌ 不可，非本人数据 |
| L2 群体懂 | 懂你这一类人 | "大学生倾向于便宜出游" | 🟡 部分可，要先解释 |
| **L3 情境懂** | **懂你此刻所处的情境** | **"五一前的周末微雨下午"** | ✅ **可，因为观众也在此刻** |

本方案押 **L3 情境懂**。它是**展台可感知**的唯一路径。

### 一句话总结

> 观众被 wow 不是因为"系统懂了 TA"，而是因为"**系统懂了'此刻'这件事，而 TA 此刻也在'此刻'里**"。

## 概念的三层结构

这个方案的概念结构可以拆成三层：

```
┌────────────────────────────────────────────┐
│  媒介层：情境预言胶囊                       │  ← 新数据形式
│  （7 层 schema、可执行、可变形、可反馈）    │
├────────────────────────────────────────────┤
│  认知层：L3 情境懂                          │  ← 新"懂"的定义
│  （从懂个体转到懂此刻）                     │
├────────────────────────────────────────────┤
│  展台层：feed 沉浸 + 评委侧屏（γ 双模）     │  ← 新体验形态
│  （观众模式稳、评委模式真）                 │
└────────────────────────────────────────────┘
```

- **媒介层**回答 "What is it"（这是什么）
- **认知层**回答 "Why does it work"（为什么立得住）
- **展台层**回答 "How do people see it"（怎么让人看到）

三层同时成立，方案才立得住。

## 与"响应式 AI"的根本区别

| 维度 | 响应式 AI（ChatGPT / Perplexity / 搜索） | 预言式 AI（本方案） |
|---|---|---|
| 触发 | 用户主动问 | 系统主动推 |
| 时间 | 此刻 | 未来预言时刻 |
| 面向 | 个体 | 情境 |
| 输出 | 答案 | 决策胶囊 |
| 交互 | 对话轮次 | 变形 + 反馈 |
| 可审计 | 部分（引用） | 全链路 trace |

本方案不是做一个"更好的 Perplexity"，是做一个**不同的东西** —— 从"响应"转到"预言"，从"问题"转到"情境"。
