## 推演原则

本次推演遵循 brainstorming skill 的 4 条原则：

1. **一次一问**——避免多问题混淆
2. **多选题优先**——给候选 + 推荐 + tradeoff
3. **YAGNI 严格**——每层都问"是否必要"
4. **可回溯**——每个决策留下"为什么这么选"的记录
