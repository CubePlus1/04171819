# Q1 · wow 机制推演

## 问题

> "参考图给出了两个关键信号：(1) 单张卡聚合（不是多卡对比）(2) feed 流内嵌刷到（不是独立页面）。
> 这跟之前讨论的 `brainstorming-02` 三列分叉路线是不同的 wow 机制。你想选哪个主 wow？"

## 候选

| 选项 | 描述 | tradeoff |
|---|---|---|
| A | 按参考图：单卡"刚好懂" | 太像官方示意，原创度低 |
| B | `brainstorming-02` 路线：三列"同题分叉" | 违反题面"刚好"关键词 |
| C | 融合：feed 里刷到单卡，单卡内部展示分叉 | 工时最大 |
| D | 另有想法 | — |

## 用户选择：**D**

用户给出的完整愿景：

> 我们要做的是不仅仅是一张卡，是一个**新媒体赛道**。
> 我们需要调动**视觉、听觉**，最大化，**决策助手，直接出成果**，不要局限于推荐，
> 主要是帮助用户**头脑风暴**，去**提前搜集，自主 RAG+ETL**，去猜想要的信息、情绪与选择，都刚好准备好。
> 而且可以**主动触发**，包括用户可以做到**反馈，重新加强**我们的推荐，
> 但是我们主要做的是**展示，定义新的信息流**，**不局限于卡片**。

---

## 关键要素拆解

| 特性 | 含义 | 对设计的影响 |
|---|---|---|
| 不仅仅是一张卡 | 不是 UI 增强，是**媒介级**重构 | 要创造新数据形式 |
| 调动视觉、听觉 | 多模态 | 必须有 TTS + 动态视觉 |
| 决策助手 + 直接出成果 | 不是推荐，是**决策**输出 | 要有 action 层 |
| 帮助头脑风暴 | 主动发散而非被动响应 | 要有变形层（多参数） |
| 自主 RAG + ETL | 后台 agent 持续跑 | 要有 agent trace 层 |
| 主动触发 | 不等用户搜，系统预言 | 要有时间预言（predicted_moment） |
| 用户反馈重新加强 | 闭环强化学习 | 要有反馈层 |
| 主要做展示 | 游园会即产品 | 展台即评审 |
| 定义新的信息流 | 范式级目标 | 创新数据类型 |

---

## 用户愿景的分解

这段话看似散，实际上提出了一个**完整的设计框架**：

### 1. 范畴层 · "新媒体赛道"

不是做一个产品，是定义一种类型。

### 2. 感官层 · "调动视觉、听觉"

信息 + 情绪 同时对齐题面"信息、情绪与选择，都刚好准备好"。

### 3. 输出层 · "决策助手，直接出成果"

取代传统"推荐"模型。不是 suggest，是 decide + execute。

### 4. 生成层 · "主动触发 + 自主 RAG + ETL"

Agent 主动跑，不等用户问。

### 5. 反馈层 · "反馈重新加强"

闭环强化学习。

### 6. 输出形式层 · "不局限于卡片"

允许跳出传统 UI。

---

## 我的回应

因为用户否定了 A/B/C 三个窄候选，并给出了更大的愿景，我把下一个问题拉高到"**载体形态**"层级，进入 Q2。

本轮的 insight：
- 用户不是在选"哪个 UI 样式"
- 用户是在选"**一个新媒介的边界**"
- 后续所有问题要围绕"新媒介"而不是"好 UI"展开

## 推演决策

| 项目 | 决策 |
|---|---|
| wow 机制 | 不走 ABC 任一个，走 D 自定义 |
| 目标层级 | 媒介级（不是 UI 级） |
| 关键要素 | 新数据形式 + 主动触发 + 决策输出 + 反馈闭环 + 多模态 |
| 下一个问题 | Q2 载体形态 |
