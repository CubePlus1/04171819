# 阶段 0 · 四赛道筛选

## 起点：四赛道

字节 Hackathon 2026 有四个赛道：

| 赛道 | 主题 |
|---|---|
| 赛道一 | 互动空间 |
| 赛道二 | 抖音精选-内容重构 |
| 赛道三 | AI 体验｜刷到懂你的瞬间 |
| 赛道四 | 视觉搜索 |

前置调研已沉淀在两份报告：
- `../../four-tracks-deep-analysis.md`：四赛道深度解析（基于 35 个候选方向）
- `../../002.md`：四赛道策略判断（"赛道 2 做脑子、赛道 3 做脸"的组合论）

---

## 排除赛道一

### 理由：结构性错位

| 官方容器 | 个人开发者状态 |
|---|---|
| 抖音互动工具 | "新插件暂不开放申请" |
| 直播玩法 | 需提案评估 |
| 小游戏 | 审核 2-5 天 |
| `web-view` | 需业务域名 + ICP 备案，个人类型不支持 |
| 直播互动 | 需真实直播间调试 |

**结论**：官方容器全部对参赛者关闭。所有赛道一方向被迫降级为本地 Web/H5 → 报赛道一但交付的是 Web 页面 → **赛道定义与可实现方案的结构性错位** → 答辩风险。

---

## 排除赛道四

### 理由：scope 失控 + 资产不可继承

| 追求 | 崩溃点 |
|---|---|
| 视频端内取帧 | 抖音无公开接口 |
| 开放域物体识别 | 40h 训不出，多模态延迟不稳 |
| 跨平台比价 | 淘宝 / 京东 API 需企业资质 |
| 自由框选任意轮廓 | 识别精度崩 |

**即使收窄垂类**：
- 80% 工时在**素材准备和热点标注**（40h 里 20h 做标注）
- 必须预置 6-12 张 hero 素材
- 必须降级到热点点选
- **跟数字建模人目标完全无关**（视觉识别资产无法继承到 PersonVec）

**结论**：死在"链路太长 + 时间花在标注上 + 资产不可继承"。

---

## 赛道二 vs 赛道三 · 权重反转

这是本次推演最关键的一个权重决策。

### 原始分析（来自 `../../four-tracks-deep-analysis.md`）

| 权重 | 赢家 |
|---|---|
| 长期技术契合（PersonVec、ETL 管线继承） | 赛道二 |
| 比赛赢面（demo_wow、10 秒理解） | 赛道三 |

用户原始偏好是**赛道二**。

### 用户明确的权重转移

> **"权重在体验上，游园会拉大，我们需要体验效果好，然后抓眼，wow。"**

这句话把评估权重从"长期技术契合"切到"游园会体验"，导致结论**反转**。

### 新权重下的赛道对比

| 体验维度 | 赛道二 | 赛道三 |
|---|---|---|
| 第一眼抓眼（0-3s） | 🔴 弱（要先看懂题） | 🟢 最强（视觉对比 / 单胶囊冲击） |
| 10 秒理解门槛 | 🔴 高（读课程卡 / 路线图） | 🟢 最低 |
| 展台吞吐 | 🔴 慢（3 分钟深读） | 🟢 最快（60-95s 一轮） |
| 排队围观 | 🔴 后排看不到 | 🟢 强（远距离可见） |
| wow 冲击可控 | 🟡 依赖内容质量 | 🟢 可编程（硬过滤 + 预计算） |
| 评委第一印象 | 🔴 "又一个摘要工具" | 🟢 强品类印象 |
| demo_wow 天花板 | 8（bytecamp-02 极限） | **9.5**（brainstorming-02） |

### 赛道二的三道结构性天花板

| 天花板 | 为什么救不了 |
|---|---|
| ❌ 读懂门槛高 | 观众要读课程卡 / 路线图 / 行动板才懂价值 |
| ❌ 展台吞吐慢 | 观众需要停留 30 秒+ |
| ❌ "视频摘要工具"认知陷阱 | 评委初看会归类为 summarization |

### 结论

**选赛道三。**

## 赛道三题面的再确认

赛道三题面强调 "**在被刷到的那一刻，把信息、情绪与选择刚好准备好**"。

这个描述精准对齐"游园会体验"权重：
- "刷到的那一刻" = 瞬间感（第一眼 wow）
- "刚好准备好" = 精准感（不需要深度体验）
- "信息、情绪与选择" = 多模态（视觉听觉冲击）

**赛道三的题面本身就是为"游园会展台"设计的**。这个赛道选择不仅在权重下最优，在题面原生契合度上也最高。

|---|---|---|

| **赛道三** | ✅ **主选** | 体验权重下全面胜出，题面原生契合 |
