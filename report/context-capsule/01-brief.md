# 01 · 官方题面深读 + 参考方案解读

## 官方题面（原文）

### 赛道三｜AI 体验：刷到懂你的瞬间

> 在抖音，用户每天都会刷过无数条内容，但真正让人停下来的，往往是那一刻——刚好被懂、刚好被满足。
>
> 这一次，我们不再只做视频。我们希望你去创造一种新的信息流内容单元。它不只是被观看，而是在被刷到的那一刻，把你想要的信息、情绪与选择，都刚好准备好。
>
> 它可以是在你纠结今晚吃什么时，刷到一桌已经帮你搭好的美食；也可以是在你准备出门旅行时，刚好出现的一份行程安排；也可能是在一场比赛开始前，把你最关心的阵容和看点提前呈现出来。
>
> 用户不需要跳转，也不需要理解复杂逻辑，而是在刷的过程中，遇到那些"刚好懂你"的瞬间。

---

## 关键词拆解

| 关键词 | 含义 | 对本方案的约束 |
|---|---|---|
| **"新的信息流内容单元"** | 要**定义新媒介**，不是在旧媒介上迭代 | 必须提出一种新数据对象，不能是卡片或视频的变体 |
| **"不只是被观看"** | 内嵌决策 / 行动 / 变形能力 | 必须有可执行层、可变形层 |
| **"在被刷到的那一刻"** | feed 内嵌，不跳转 | 单单元完成闭环，不能依赖二级页面 |
| **"刚好准备好"** | 主动预言，不等用户搜 | 触发机制前置，系统先动 |
| **"信息、情绪与选择"** | 三位一体 | 多模态：信息（结构化）+ 情绪（听觉/视觉）+ 选择（决策） |
| **"刚好懂你"的"刚好"** | 精准，不是多样 | 单个单元就够，**不是多解分叉** |
| 吃 / 旅行 / 赛事 | 三个官方示例 | 决策型场景，不是信息消费型 |

### 最关键的一个词："**刚好**"

"刚好懂你"的英文翻译不是 "understand you diversely"，是 **"just right"**。这意味着官方期待的 wow 来自**精准感**，而不是**多样性**。

这一点是对"三列多解分叉"类方向（如 `brainstorming-02`）的一个隐性否定。本方案尊重这个"刚好"——单胶囊 + 变形，而不是多胶囊并列。

## 参考方案解读

官方提供了一份内部参考方案截图（`../dimage.png`）。它是一张"AI 生成"的莫干山清明越野跑攻略聚合卡：

```
┌──────────────────────────────────────┐
│ 关注 | 经验 | 北京 | 严选 | 商城 | 推荐 │   ← feed tab
├──────────────────────────────────────┤
│                                      │
│  莫干山清明越野跑攻略      [AI生成]  │   ← 标题 + AI 标识
│                                      │
│  目的地       天数        气温预估   │
│  湖州·莫干山  2 天       15-25℃      │   ← 结构化字段
│  路线风景     植被丰茂               │
│                                      │
│  [Day 1]---------  [Day 2]           │   ← 路线图
│                                      │
│  运动&旅行博主攻略                   │
│                                      │
│  去越野跑吧！钻林子当猴子其乐无穷！ │   ← 博主原话 chip
│  笨蛋哒：去自然里坐坐好呀…      🎬  │
│                                      │
│  莫干山山顶喝咖啡超 nice！           │   ← 第二条 chip
│  淡入周末，雨入进山…            🎬  │
│                                      │
│  [不感兴趣]         [查看详情]       │
│                                      │
│       ↑ 上滑继续看视频               │
└──────────────────────────────────────┘
```

### 这张卡的设计语言

1. **单卡聚合**（不是多卡并列）
2. **AI 标识**（合规 + 透明）
3. **结构化字段**（目的地 / 天数 / 气温 / 路线）
4. **博主原话 + 视频缩略图**（证据可追）
5. **feed 内嵌**（上下能继续刷）
6. **两个决策按钮**（不感兴趣 / 查看详情）

### 这张卡的不足（本方案要解决的）

- ❌ **被动**——等用户刷到，不主动预言
- ❌ **静态**——不会随情境变形
- ❌ **单模态**——只有图文，没有语音 / 动态
- ❌ **单人格**——没区分寝室三人 vs 情侣 vs 独自
- ❌ **黑盒**——不暴露"为什么推给我"
- ❌ **"清明"已过时**——当前是 4-17，清明已过，时间感断裂

**情境预言胶囊 = 把这张卡从"AI 聚合卡"升级成"AI 原生的新数据单元"。**

参考方案是 v0，情境预言胶囊是 v1。

## 本方案如何对齐题面

| 官方诉求 | 情境预言胶囊如何兑现 |
|---|---|
| "创造一种新的信息流内容单元" | 胶囊是 7 层结构的全新数据对象，区别于卡 / 视频 / 对话 |
| "不只是被观看" | 决策层 + 变形层 + 反馈层让单元**可执行、可变形、可反馈** |
| "在被刷到的那一刻" | feed 沉浸形态 + `now` / `predicted_moment` 双时间锚点 |
| "信息、情绪与选择，都刚好准备好" | 内容层（信息）+ TTS/视觉情境（情绪）+ 决策层（选择） |
| "不需要跳转，不需要理解复杂逻辑" | 单胶囊聚合 + 结构化字段 + 语音播报 + 直接决策 |
| "刚好懂你" 的 **"刚好"** | 不做多解分叉，做**单胶囊 + 参数化变形** |
| 官方示例 吃 / 旅行 / 赛事 | 五一春游主 demo + 晚饭 bonus，已覆盖 2/3 |

详细概念设计见 [`03-concept.md`](03-concept.md)。
