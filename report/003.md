## 核心方案（已 lock）

**赛道三 · 情境预言胶囊（Context Capsule）**

一种新的信息流数据单元，在你刷到的那一刻，系统已经把你下一个决策点的信息、情绪与选择准备好。

**不是卡片、不是视频、不是对话**，是一个"**可执行、可变形、可反馈、可审计、带时间预言的多轨情境对象**"。

### Schema v1.0 · 7 层

```
① 情境层   situation_vec (now + predicted_moment + event + group + mood)
② 内容层   title + hero_visual + tts_narration + structured_fields
③ 证据层   evidence_chips (博主原话 + 视频缩略图)
④ 决策层   decisions (直接出成果)
⑤ 变形层   forks (by_location / by_group / by_budget)  ← 需改名"再刷一下"
⑥ 反馈层   feedback_anchors (语义化 dampen/boost)
⑦ Agent trace 评委可见
```

### 重新定义"懂你"

从 **L1 个体懂** 改为 **L3 情境懂**：不懂你是谁，懂你此刻所处的情境。观众和路过者**共享同一个"此刻"**（4 月 17 日的春末，距五一 14 天，大学生群体）。

## 故事 5 幕结构（已设计，等爱好注入）

```
【第 1 幕 · 背景 5-10s】
   一个 [爱好] 的大学生，[某个真实生活时刻]
   刚打开抖音，心里想着 [某件马上要做的事]

【第 2 幕 · 刷到 3-5s】
   滑两下，第三条 —— 不是视频不是广告
   是一张 AI 原生的情境预言胶囊
   他停下来了

【第 3 幕 · 被打动 10-15s】
   TTS 响起，胶囊展开
   他看到真的需要的信息 / 情绪 / 选择
   胶囊**恰好就是他此刻要的**

【第 4 幕 · 互动 5-10s】
   极轻动作（点一下 / 停留一下）
   胶囊响应 → 变形为下一版
   用完即走

【第 5 幕 · 再次刷到 5-10s】
   第二天同时间
   又刷到一张，但长得不一样了
   胶囊在成长，他开始期待下一次

【结局 · 10-15s】
   这不是卡 / 视频 / 对话
   这是一种新的信息流单元
```

## 关键原则清单（回来记住）

- **展示 > 技术**（老师明确）
- **故事 > 系统**（叙事驱动）
- **后端 lite**（不真跑 RAG，全预制）
- **真实爱好**（必须从团队真心关心的事出发）
- **一瞬间成立**（0-3s 胶囊已在，无铺垫）
- **刷到即用**（不是功能操作，是 feed 语义）
- **被打动 > 被懂**（情感 > 认知）
- **期待再刷到**（持续演化暗示）
