# 07 · 醒来后前 2 小时行动清单

> 严格收敛 · 只做最值钱的事情 · 不允许增加功能 · 不允许提新方案。

## 唯一目标

**让醒来后的 2 小时把展台准备到"立刻可上"的状态。**

代码已经够了。你要做的不是写更多 · 是**讲得清、演得稳、打得动**。

## 6 件事 · 按优先级

| # | 事项 | 时长 | 产出 |
|---|---|---:|---|
| 1 | 练爷爷剧本讲稿 | 30min | 10s / 90s / 3min 三档 · 录音自检 |
| 2 | 写展台启动脚本 `npm run demo` | 15min | 一条命令 reset + 打开浏览器 |
| 3 | 右面板文案收一下（去 demo 术语） | 15min | TriggerPicker / AmbientPulse |
| 4 | 3 个常见质疑的 30 秒备答 | 20min | pitch 附卡 |
| 5 | 录 45 秒 fallback 录屏 | 20min | mp4 桌面上 |
| 6 | Echo 冻结标签 | 10min | README · 展台不展 |

**总时长：110 分钟 ≈ 2 小时**。

## 详细执行

### 1 · 练爷爷剧本讲稿（30 分钟）

#### 材料
- `studydocs/09-pitch-10sec.md` · 10 秒卖点
- `studydocs/10-pitch-90sec.md` · 90 秒完整讲稿
- `studydocs/11-pitch-3min.md` · 3 分钟深演版

#### 流程
1. 读一遍 `10-pitch-90sec.md` 完整版（3 分钟）
2. 合上文档 · 自己说一遍（录音）
3. 听录音 · 标出"卡住"和"语气虚"的地方（3 分钟）
4. 重新读原文 · 对照修正（3 分钟）
5. 再录一次（3 分钟）
6. 重复步骤 3-5 直到录音听起来自然（≤ 15 分钟）

#### 通过标准
- 90 秒 ± 5 秒稳定（录手机计时）
- 某一句忘了能接下一句 · 不从头重来
- 眼神能落在评委身上 · 不一直盯屏幕

#### 背下来的核心段
**"爷爷剧本"的 3 句话**（60% 的 pitch 价值在这里）：

> "您 2 周前在爷爷档案下评论过'蹲后续爷爷真帅' ——
> 您当时就是随手打了一句 · 打完就刷走了。
> 然后 2 周过去 · 您应该忘了吧。
> 但系统一直替您记着 · 今天爷爷的老战友刚好联系到他了。
> 您当时那句话 —— 这次它替您等到了。"

这 5 句话**反复练 · 滚瓜烂熟** · 展台现场哪怕忘了其他段也能救场。

### 2 · 写展台启动脚本（15 分钟）

#### 目标
一条命令把展台准备到"评委可立刻看的状态"：
1. 清库到初态
2. 启动后端
3. 启动前端
4. 打开浏览器到默认主题 + 默认路径

#### 实现
在 `demo/package.json` 加一条 script：
```json
{
  "scripts": {
    "demo": "npm --prefix backend run db:seed && npm run dev"
  }
}
```

`npm run dev` 已经有（concurrently 启前后端）。只是在前面加一步 reset-like 的 db:seed。

更彻底的版本（可选）：
```json
{
  "scripts": {
    "demo": "npm --prefix backend run db:seed && concurrently -k -n backend,frontend,browser -c blue,magenta,green \"npm --prefix backend run dev\" \"npm --prefix frontend run dev\" \"sleep 4 && open http://localhost:5173\""
  }
}
```

（`open` 是 macOS 的命令 · Windows/Linux 要换）

#### 通过标准
- 展台电脑上敲 `cd demo && npm run demo` 然后等 5 秒
- 浏览器自动打开 · 履约卡片开始浮入

| 接下一条 | 立刻接一条 |

（`studydocs/` 和现有代码里部分已经改过 · 检查一遍还有没有漏网）

#### 具体文件

### 4 · 3 个常见质疑的 30 秒备答（20 分钟）

#### 需要准备的 3 个问题
1. "双面板是真实产品吗？"
2. "你的 AI 是规则引擎还是真 LLM？"
3. "你们有多少代码审查？"

#### 各写 30 秒答案 · 写在一张纸/电脑便签上 · 展台前放在兜里

参考 `studydocs/12-faq.md` 的 Q14 / Q6 / Q12。

**关键是 2 秒内给出方向结论**：
- ❌ "这个问题有点复杂 ——"
- ✅ "右边是 AI 透明化视图 · 不是真实产品 UI。"

#### 练习
对着镜子说 3 遍。
每个问题的答案不超过 3 句话。
每句 15-20 字。

### 5 · 录 45 秒 fallback 录屏（20 分钟）

#### 目标
WiFi / 电脑 / 后端任何一个挂了 · 可以拿手机放录屏救场。

#### 流程
1. 本地跑一遍 · 确认三剧本都浮入
2. 用手机**录屏 45 秒**（设定好剧本顺序）：
   - 前 5s 静止 · 让评委读标题
   - 5-20s · 剧本 A 浮入 + P1 情景
   - 20-35s · 剧本 C 浮入 + P1/P2/P3 多页
   - 35-45s · "过去 × 此刻 · 一人一张" 收尾（用文字叠加）
3. 存到展台电脑桌面 · 命名 `fallback-45s.mp4`

#### 通过标准
- 手机能立刻播
- 不依赖网络
- 45 秒看完能理解产品
