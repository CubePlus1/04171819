## 方向 1：数字学伴 — 视频变私教（赛道二）

**概念**：用户选择感兴趣领域，系统从抖音精选视频中 ETL 提取知识 → 构建个人知识图谱 → 根据用户画像生成个性化学习路径 + 互动测验。

**复用**：nightowl 的 ETL 管线 + Eoove 的画像融合 + 知识图谱可视化

**展示亮点**：现场输入一个视频 → 30秒后生成交互式课程卡片 + 知识图谱

### 可行性调查 Prompt

```
帮我调查"数字学伴"项目的技术可行性：

1. **视频转文字 API**：
   - 字节跳动火山引擎 ASR API 是否开放？价格？免费额度？
   - 搜索 "火山引擎 语音识别 API 开发者 免费额度 2025 2026"
   - 备选：Whisper API / 讯飞开放平台的免费额度

2. **抖音视频内容获取**：
   - 抖音精选是否有开放 API 获取视频内容/字幕？
   - 搜索 "抖音开放平台 API 视频内容 字幕 开发者"
   - 抖音精选与普通抖音的 API 区别？
   - 是否可以用抖音小程序 SDK 获取当前播放视频信息？

3. **字节跳动 Coze 平台**：
   - Coze 是否支持 RAG 知识库 + 自定义 Agent？
   - 搜索 "Coze 扣子 知识库 RAG API 2025 2026 hackathon"
   - Coze 的免费额度和 API 调用限制？

4. **知识图谱前端可视化**：
   - D3.js / ECharts / AntV G6 哪个更适合 40 小时内做出好看的知识图谱？
   - 是否有现成的交互式知识图谱模板可以直接用？

5. **竞品分析**：
   - 搜索 "抖音 知识学习 AI 课程生成" 看是否已有类似产品
   - 搜索之前字节跳动 hackathon 获奖项目中是否有类似方向
```

## 方向 12：多源融合画像 — 你的数据全景图（赛道二 或 赛道三）
